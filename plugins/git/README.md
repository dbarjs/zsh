# git

Short aliases for everyday git commands.

## Aliases

| Alias | Expands to |
|---|---|
| `g` | `git` |
| `gst` | `git status` |
| `gco` | `git checkout` |
| `gcm` | `git commit -m` |
| `gp` | `git push` |
| `gl` | `git pull` |

## Install (Sheldon)

```toml
[plugins.git]
github = "dbarjs/zsh"
dir = "plugins/git"
```
